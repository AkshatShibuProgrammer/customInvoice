## Overview

The Customizable Invoice Generator is a client-side web application and local document generation toolkit. Its core frontend is built with React 19, TypeScript, and Vite, featuring an AI natural language assistant parser, manual multi-order invoice editor, live A4 print-ready preview, and single-file HTML/PDF export capabilities. In addition, the repository includes a Python/SQLite backend toolkit for managing and rendering historical reimbursement claims (such as meal and ride receipts).

## Components

### 1. Core React App & Workspace State
- **Purpose:** Manages root application lifecycle, switching between AI assistant and manual editor modes, and local browser persistence.
- **Location:** `src/App.tsx`, `src/utils/workspace.ts`
- **Pattern:** Controlled React state container with persistent LocalStorage fallback.

### 2. AI Assistant & Parser
- **Purpose:** Parses natural language descriptions, restaurant orders, dates, and amounts into structured draft invoices.
- **Location:** `src/components/AssistantPanel.tsx`, `src/utils/assistant.ts`, `src/types/assistant.ts`
- **Pattern:** Rule-based and pattern matching parser with preview verification and draft commit workflow.

### 3. Manual Invoice Form Editor
- **Purpose:** Full manual CRUD operations on restaurants, addresses, items, taxes, and order details.
- **Location:** `src/components/InvoiceForm.tsx`, `src/types/invoice.ts`, `src/utils/validation.ts`
- **Pattern:** Tabular and structured form controls with dynamic item and tax calculation (`calc.ts`).

### 4. Invoice Previews & Templates
- **Purpose:** High-fidelity, print-ready A4 rendering supporting multiple invoice templates (Type 1 standard, Type 2 alternative).
- **Location:** `src/components/InvoicePreview.tsx`, `src/components/InvoiceType1.tsx`, `src/components/InvoiceType2.tsx`
- **Pattern:** Modular presentation components styled with utility CSS and dedicated print media stylesheets.

### 5. Standalone Generator & Export
- **Purpose:** Exports fully bundleable standalone HTML files and print dialogs for zero-dependency offline rendering.
- **Location:** `src/components/DownloadDialog.tsx`, `src/utils/standalone.ts`
- **Pattern:** Template serialization injecting state into single-file portable HTML.

### 6. Reimbursement Toolkit & Database Scripts
- **Purpose:** Standalone Python automation scripts and SQLite storage for tracking claim items, chronologically sequencing bills, and generating PDFs.
- **Location:** `init_db.py`, `validate_db.py`, `apply_chronological_invoices.py`, `reimbursement.db`, `akshat-reimbursement.html`, `mayank-reimbursement.html`
- **Pattern:** Relational SQLite schema with Python CLI validation and static HTML reporting.

## Data Flow

1. **Input Mode:**
   - **Assistant Mode:** User inputs plain text or meal breakdown -> `AssistantPanel` calls `assistant.ts` -> parsed draft displayed in `InvoicePreview` -> user clicks Apply -> merged into `AppData`.
   - **Manual Mode:** User edits order items, tax percentages, or addresses in `InvoiceForm` -> updates state in `App.tsx` -> autosaved to `localStorage` via `workspace.ts`.
2. **Calculation:**
   - Order items and taxes are dynamically calculated using `calc.ts` ensuring subtotal, CGST/SGST/IGST, discounts, and roundoff sums are exact.
3. **Export / Output:**
   - User triggers Download or Print -> `standalone.ts` creates a portable self-contained bundle or triggers standard browser `window.print()` targeting `@media print` A4 styles.
